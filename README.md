# spinly-privacy

The public pages for the [Spinly](https://github.com/elmehdimotaqi-ui/spinly) iOS app and Spinly for Android,
served by GitHub Pages:

| Page | Address | Source |
| --- | --- | --- |
| Privacy policy | <https://elmehdimotaqi-ui.github.io/spinly-privacy/> | `index.md` |
| Support | <https://elmehdimotaqi-ui.github.io/spinly-privacy/support/> | `support.md` |
| Android privacy policy | <https://elmehdimotaqi-ui.github.io/spinly-privacy/android/> | `android/index.md` |

These addresses are what App Store Connect and Google Play have on file, so **they must not change** — renaming this
repository would break them.

`index.md` is a copy of `PRIVACY_POLICY.md` in the app repository, below three lines of Jekyll
front matter. Change both together, and move the effective date whenever the text changes: the
policy promises the current version is at that address.

`android/index.md` comes from `docs/privacy-policy.md` in the Android app repository (the markdown block under
"Page content"). The same rule applies: change both together and move its effective date.
